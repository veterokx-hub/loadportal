1. Получите URL портала:
{{- if .Values.ingress.enabled }}
   https://{{ .Values.ingress.host }}
{{- else }}
   kubectl port-forward svc/{{ include "loadtest-portal.fullname" . }}-frontend 3000:3000 -n {{ .Release.Namespace }}
{{- end }}

2. Вход по умолчанию (смените после первого входа!):
   admin / admin

3. LDAP настраивается в UI: Настройки → LDAP / AD (только admin).

4. Проверка health:
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

Документация: docs/deploy/k8s.md
