# Интерфейс

Код: `frontend/`. Состояние черновика: `frontend/context/PortalContext.tsx`, ключ `ltp-state-v1`.

## Шаги сценария

| Индекс | URL | Экран |
|---|---|---|
| 0 | `/scenario/source` | Спецификация, пустой лист, открыть сборку |
| 1 | `/scenario/requests` | Базовый URL, метод, путь, свой URL запроса |
| 2 | `/scenario/correlation` | Параметры, извлечения, датасеты, проверки |
| 3 | `/scenario/intensity` | RPS, AutoStop, движок, сохранить и скачать |

Шаги вперёд по мастеру ограничены `maxReached`. Клик по строке Здоровья открывает нужный шаг, даже если он ещё закрыт, и скроллит к полю. Механика: `frontend/lib/health-focus.ts`.

## Здоровье

Считается на клиенте, `frontend/lib/readiness.ts`. Сеть не нужна.

Ошибки блокируют «Далее», где это завязано на обязательные пустые параметры. Предупреждения о переменных скрипта «Далее» не блокируют. Сохранить сборку можно и с замечаниями.

Типичные строки:

| Строка | Куда ведёт клик |
|---|---|
| Нет запросов | Форма добавления запроса |
| Нет базового URL | Поле базового URL |
| Обязательный параметр пуст | Строка параметра |
| Корреляция без извлечения выше | Этот параметр. В тексте указаны вкладка и имя параметра |
| Переменная задаётся несколько раз | Каждый писатель: извлечение, датасет или параметр |
| Колонка есть в нескольких датасетах | Карточка датасета |
| Имя в Gatling станет другим | То же поле |
| Колонки нет в датасете | Карточка датасета |
| 0 RPS, высокий RPS | Таблица интенсивности |
| AutoStop выключен | Блок AutoStop |

Плейсхолдер `{param2}` в пути и переменная `${param}` — разные имена. Строка Здоровья называет параметр и вкладку, а не только заголовок запроса.

## Параметры на шаге корреляции

Вкладки Header, Query, Body, Path. Path есть, только если в адресе есть `{…}`.

Новая строка Query получает имя `param`, следующий — `param2`. Header: `Header`, `Header2`. Body: `field`, `field2`. Это имена HTTP, не переменные, пока источник не счётчик и не случайная строка.

Одинаковые имена Query в одном запросе портал не запрещает. В скрипт уйдут два ключа. Раньше это было предупреждение «имя уже используется». Его убрали: такое имя само переменной не становится.

## Сборка

На шаге интенсивности пользователь выбирает движок. «Сохранить» вызывает `POST /api/builds/save`: в истории появляются `build_id` и `script_id`. Разовая выгрузка без истории — `POST /api/build`, `/api/build/k6`, сборка Gatling тем же контрактом сохранения.

Перед сменой сценария UI предлагает сохранить текущий черновик.

История: до 30 сборок на пользователя, хранение 30 дней, cron constructor в 03:15. В списке видно несколько строк, остальные скроллом.

## Сессия

`POST /api/auth/login` → Bearer. TTL 3 часа (`auth_sessions`). При истечении черновик в `localStorage` остаётся, на экране входа об этом написано.

Первый admin обязан сменить пароль. Пока флаг висит, API пускает только смену пароля и выход.

Тема и черновик живут в браузере, не в БД.
