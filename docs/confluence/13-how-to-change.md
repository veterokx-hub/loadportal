# Доработка

Порядок один: найти владельца поля, поправить его, поправить зеркала контракта, прогнать узкий тест. Ниже типичные задачи и файлы, которые обязаны поехать вместе.

## Новое поле сценария

1. `docs/domain-model.md` — имя в snake_case и кто его читает.
2. Модель frontend `frontend/lib/types.ts` и место в форме.
3. Запись constructor, которая принимает Scenario.
4. Модели Python: analyzer (если поле приходит из спецификации), k6-generator, gatling-generator, analysis если поле нужно отчёту.
5. `JmxBuilder`, если поле должно попасть в `.jmx`.
6. Тест, который кормит JSON и проверяет, что поле не потерялось. Иначе Jackson молча отбросит неизвестное, а генератор молча подставит дефолт.

Группировка запросов продублирована. Правило «корреляция или общий датасет» живёт в `frontend/lib/grouping.ts` и в каждом генераторе. Меняете правило — меняете все четыре места.

## Новая проверка Здоровья

Только клиент: `frontend/lib/readiness.ts`. Клик по строке ведёт в поле через `focus` из `frontend/lib/health-focus.ts`. Если строка не скроллит, у шага нет обработчика этого `focus`, его добавляют в компонент шага (`Step1Source`, `Step2Requests`, `Step3Correlation`, `Step4Intensity`).

Предупреждение о переменной скрипта не должно блокировать «Далее». Ошибка пустого обязательного параметра блокирует.

Сравнение имён — только писатели из `frontend/lib/script-vars.ts`. Не возвращать проверку «два Query с одним именем» и «извлечение совпало с именем path, который его читает». Имя path само переменной не является.

## Новый источник значения параметра

`ParamSourceEditor`, тип `source.kind` в types, отрисовка в трёх генераторах, разбор в analyzer если источник должен появляться из OpenAPI. Здоровье: `sourceFilled` в `frontend/lib/request-params.ts`.

Если источник пишет переменную, добавить ветку в `scriptWriters`. Если только читает, как корреляция, в писатели не добавлять.

## Новый движок

Отдельный сервис по образцу k6-generator, URL в `config/consul-vault-config.yaml` и local yaml, вызов из constructor `BuildController`, пункт в селекторе движка, значение `scripts.engine`, ветка upload если нужен свой суффикс файла. Пайплайн `ci-runner` и `lt-run` — отдельная задача: портал только отдаёт файл и `engine`.

## Новое правило анализа

Каталог `analysis/app/catalog/`: метрика, правило, гипотеза. Версия ruleset должна смениться, иначе старые отчёты нельзя отличить от новых. «Пересчитать» создаёт новую строку и берёт каталог текущей версии сервиса.

Детектор не ходит в Postgres и не в GitLab. Вход — окно и селекторы цели, выход — JSON отчёта.

## Новый модуль меню

`frontend/lib/modules.ts` (`available: false`, пока экран пустой), `frontend/lib/routes.ts`, пункт в `AppModulesNav`. Пока `available` ложь, роут показывает заглушку. Не обещать в тексте кнопки поведение, которого нет.

## Новая настройка

Несекрет: ключ Consul KV и чтение в том сервисе, которому она нужна. Запасное значение в `consul-vault-config.yaml`, не `@Value` по полям. Секрет: путь Vault и резолвер, локально env. Экран настроек в UI сейчас нет: GitLab и LDAP правятся ключами, API `GET/PUT /api/settings/gitlab` и `/api/settings/ldap` остаётся для отладки.

## Схема БД

Новый файл в `constructor/src/main/resources/db/changelog/`, включить в master. Колонка, которую читает orchestrator, живёт в той же базе. После changelog — init-job на стенде, затем выкладка подов. Ручной `ALTER` на проде разойдётся с validate на следующем деплое.

## Текст интерфейса

Строки на русском, в компонентах. Подсказка Здоровья должна называть параметр и вкладку, не только заголовок запроса. Пометка `(Gatling)` ставится, когда конфликт есть только в Gatling (случайная строка или переписанный идентификатор).

Подложка бирюзового поля — класс `script-var` в `frontend/app/globals.css`. Её ставят на поле, чьё значение станет именем переменной: извлечение, имя счётчика и случайной строки, textarea CSV. Обычный Query её не получает.

## Чего не делать в рамках «маленькой правки»

Не тащить Spring Cloud. Не ставить `"type": "module"` во frontend. Не переименовывать колонку CSV в имя UI-параметра в одном генераторе: сейчас заголовок колонки — общее имя во всех трёх, и Здоровье сравнивает заголовки. Такое переименование — отдельное изменение контракта, с копией значения в имя параметра и с отказом публиковать сырой заголовок.
