# Load Test Portal — пространство документации

Источник для переноса в Confluence. Одна страница файла — одна страница пространства. Язык страниц русский, как у продукта.

Глубина: middle-разработчик должен найти модуль, контракт, конфиг и типичный сбой, не читая весь репозиторий. Построчное описание генераторов JMeter, k6 и Gatling сюда не копируется: оно живёт в коде и в `docs/module-3-pipeline.md`, `docs/domain-model.md`, `docs/module-3-run.md`, `docs/module-4-analysis.md`, `docs/metrics.md`.

## Как переносить в Confluence

1. Создать пространство или родительскую страницу «Load Test Portal».
2. Импортировать файлы по номерам. Внутренние ссылки вида `01-product.md` заменить на ссылки страниц Confluence.
3. Диаграммы из `docs/module-3-pipeline/*.svg` вложить в страницу «Пайплайн».
4. Секреты в эти страницы не копировать. В тексте только имена ключей Vault и Consul.

Дата среза: октябрь 2026, репозиторий `loadtest-portal`. Манифесты k8s и Argo в этом репозитории отсутствуют.
